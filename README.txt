PARTICLES - UNITY VFX ASSIGNMENT

Unity version: 6000.3.9f1

Three effects: Transformation, Elemental Bending, Boss Aura.

Open the project through Unity Hub. The setup script creates the scene and prefabs
on first import. You can open Assets/Scenes/VFX_Showcase.unity if needed.

The scene objects are visible in the Hierarchy without pressing Play.
Expand the Particles group under each effect to inspect each Particle System.

Play mode keys:
0 - all effects
1 - transformation
2 - elemental bending
3 - boss aura
R - restart the particle effects

Tools > VFX Showcase > Validate Saved Scene checks the setup.
Tools > VFX Showcase > Clean Up Scene Names updates the names of an existing
scene without rebuilding its particle systems.

If you change particle settings, save the scene (Ctrl+S). Rebuilding the scene
from Tools > VFX Showcase > Rebuild Scene and Prefabs will replace scene edits.
